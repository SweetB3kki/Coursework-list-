# Учёт материальных ценностей

Учебное консольное приложение на C++ для Windows. Записи об остатках, поступлении и выбытии хранятся в двусвязном списке. Каждая запись содержит номер завода и филиала, ответственного и количество материальных ценностей.

## Возможности

- Добавление, изменение, поиск, сортировка и удаление записей.
- Сохранение и загрузка записей в двоичных файлах `.dat`.
- Сводки по остаткам для филиала и завода, экспорт отчётов в текстовые файлы.

## Сборка

Понадобится компилятор MinGW-w64 для Windows. Из папки проекта выполните:

```powershell
g++ kursach.cpp -o kursach.exe -lwinmm
.\kursach.exe
```

Исходный код находится в [kursach.cpp](kursach.cpp). Запускайте приложение из папки репозитория: оно ищет звуковые файлы меню рядом с исполняемым файлом.
